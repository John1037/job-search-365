# Account Settings

Reached via the profile menu → **Settings**, or directly at `/settings`.

## Theme

Three options: **System**, **Light**, **Dark**. Click one to apply it immediately — there's no separate save step. "System" follows your device/browser's light or dark mode setting automatically.

## Alerts

"Show alerts for events in the next" — a dropdown with **7 days**, **14 days**, **30 days**, **60 days**, or **90 days**. This controls how far ahead the dashboard's Alerts section looks for upcoming interviews and other events coming due. Changing the selection saves immediately.

## Notes

- This page doesn't include password changes — that's done via the "Forgot password?" flow on the login screen, and there's no separate "change password while logged in" option.
- Click **Back to home** at the bottom to return to the dashboard.
