# Uploading and Managing Documents

Your document library (separate from any specific job) lives under the **Documents** menu, split into four categories:

- **Manage Resumes** (US) / **Manage CVs** (elsewhere)
- **Manage cover letters**
- **Manage certificates**
- **Manage other documents**

## Uploading

1. Go to the relevant category page and click **Upload**.
2. Choose a file — accepted types are PDF, `.doc`, or `.docx`, up to 10MB.
3. For **Other documents** specifically, a dialog first asks "What kind of document is this?" — type a short description (up to 40 characters) and click **Upload**. For CVs, cover letters, and certificates, the upload starts immediately with no extra step.

If the file type isn't allowed: "Please choose a PDF or Word document." If it's too big: "File must be smaller than 10MB."

## Managing what's uploaded

Each document in the list shows its file name and upload date, plus:

- **Set as default** — marks it as the default for its category (only one default per category; setting a new one clears the old one). Already-default documents show a **Default** badge instead of the button.
- **View** — opens the file in a new tab.
- **Delete** — removes it permanently, after confirming ("Delete '{file name}'? This can't be undone.").

There's no rename option — the file keeps its original filename (or, for "other" documents, the description given at upload is shown separately, not as the filename).

## Notes

- A document uploaded here can be attached to a specific job from that job's own detail page.
- Generating a CV or a cover letter for a job automatically adds the resulting file to this same library too, so it doesn't need to be uploaded separately.
