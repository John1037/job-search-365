# Sign Up

How to create a JobSearch 365 account.

## Steps

1. From the landing page, click **Get started** (or **Sign up**, top right).
2. Fill in the sign-up form and submit it.
3. A confirmation step follows before you can log in — check the inbox of the email address you signed up with.

## Notes

- The email address used to sign up becomes the **account email** — the one used to log in. A separate "email address for applications" can be set later on the profile page, which is what appears on CVs and job applications instead.
- Already have an account? Use **Log in** instead of signing up again.
