# Scanning and Reviewing Inbox Matches

Once a Gmail account is connected via the Inbox page, it can be scanned for application-related emails to review what's found.

## Scanning

Scanning is manual — there's no automatic/scheduled scanning. Click **Scan now** on the Inbox page (it becomes "Scanning…" while it runs) whenever you want to check for new updates.

After a scan, a hint shows how many possible updates were found: "Found {N} possible update(s)." If there's nothing pending: "No pending matches. Click 'Scan now' to check for updates."

## Reviewing a match

Each match shows the email's subject, when it was received, who sent it, and a short snippet. It also shows either a suggested status (styled the same as a job status badge, e.g. "Interview scheduled") or, if the app couldn't work out what it was about, "Unable to determine content."

For each match, use the **Job** dropdown to pick which of your jobs it belongs to (defaults to "No match — pick a job"). Then:

- **Confirm** — only available once a suggested status exists and you've picked a job. Opens the same "Add event" dialog used on a job's detail page, pre-filled with the suggested event (and date/time, where applicable) for you to check and adjust before saving. Submitting there logs the event on the chosen job and removes the match from your Inbox list.
- **Dismiss** — removes the match from the list without doing anything else. There's no undo — it's gone, not just hidden.

Gmail access can be connected or disconnected from this same Inbox page.
