# Generating a Cover Letter

## Requirements

- The job's status must be "Interested."
- The job needs a job description filled in, and a CV connected to it that's a PDF file (not a Word doc). If either is missing, the **Suggest cover letter** button is disabled with a hint explaining which one to fix: "Add a job description to enable this," "Connect a CV to enable the cover letter suggestion," or "Connect a PDF CV to enable the cover letter suggestion."

## Steps

1. On the job's detail page, click **Suggest cover letter**.
2. A draft is generated automatically — no options to set beforehand (no tone/length choices). While it's working: "Drafting your cover letter…"
3. Edit the draft directly in the text box — this is both the preview and the edit surface, so just type to make changes.
4. Click **Save as cover letter** (shows "Saving…"), or **Cancel** to discard it.

## What happens on save

Two files are created and added to the user's cover-letter document library: a `.txt` copy (an easy-to-edit plain-text version, kept for future edits) and a `.pdf` version. The PDF is the one that's automatically connected to the job as its cover letter — no separate step is needed to attach it.
