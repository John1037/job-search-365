# Creating Custom CV Sections

For anything that doesn't fit skills, experience, education, or certifications — volunteering, publications, languages, interests, and so on — add a custom section. On the **CV components** page, under "Custom sections," click **Add section**.

## Fields

- **Heading** * — e.g. "Languages," "Certifications" (as a custom label if you want something different from the built-in Certifications section), "Volunteering."
- **Format** — choose **Paragraph** (free text) or **Bullet list (one per line)**.
- If Bullet list: an optional **Introduction** shown above the list.
- **Content** * — the actual text (or, for bullet format, one bullet per line).

If you choose the bullet-list format, there's a formatting tip: a line written like "Automation & CRM: Zendesk, Freshdesk, Klaviyo" will render with the part before the colon bolded as a sub-header on the CV.

Click **Save** (or **Cancel**). Entries list by heading, with "Bullet list" or "Paragraph" shown beneath, plus **Edit** / **Delete** (delete asks for confirmation).
