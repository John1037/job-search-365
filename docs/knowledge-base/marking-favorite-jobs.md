# Marking Favorite Jobs

On a job's detail page, in the right-hand action column, three buttons let you flag how much you want this job:

- **Mark Preferred** — sets it one star.
- **Mark Favorite** — sets it two stars (the highest level).
- **Clear Favorite** — removes any favorite marking (disabled/greyed out if it isn't marked at all).

Each button disables itself once that level is already applied, so you always know the current state.

## Where this shows up

Favorite-marked jobs show star icons next to their title in the jobs list, and — when no custom sort order has been set — favorited jobs are shown first (Favorite, then Preferred, then everything else), before falling back to newest-logged-first. A custom sort can still be applied on top of this if needed.
