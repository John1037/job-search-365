# Managing Your Skills

On the **CV components** page, the Skills section holds your library of individual skills as a list of chips.

## Adding a skill

1. Type the skill into the text box (e.g. "Root-cause analysis").
2. Click **Add** (only enabled once you've typed something).

## Removing a skill

Click the small **✕** on any skill chip — it's removed immediately, with no confirmation prompt.

## Notes

- There's no manual reordering — skills just appear in the order you added them.
- When generating a CV for a specific job, the skills that actually go on it are selected automatically from this library based on relevance to that job — a skill can also be added on the fly during that review step, which adds it to this library too.
