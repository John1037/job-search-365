# Adding Certifications

On the **CV components** page, under "Certifications," click **Add certification**.

## Fields

- **Issuing organization** *
- **Certification** * (e.g. "AWS Certified Solutions Architect")
- **Location** (optional)
- **Start year** / **Start month** (both optional)
- **Does not expire / currently valid** — a checkbox; if unchecked, **End year** / **End month** appear
- **Details** — a bullet-point list (e.g. a credential ID), add more with **Add detail**

Click **Save** (or **Cancel**). Entries list as "{Certification} — {Issuing organization}" with the date range beneath, plus **Edit** / **Delete** (delete asks for confirmation).
