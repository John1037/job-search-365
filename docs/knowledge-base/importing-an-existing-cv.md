# Importing an Existing CV

Instead of manually typing your whole history into CV components, you can upload an existing CV and have the app pull the details out for you to review before anything is saved.

## Steps

1. Go to **CV components** and click **Import from an existing {CV/resume}** near the top of the page.
2. Choose a `.pdf` or `.docx` file and click **Import** (shows "Reading…" while it works).
3. Review what was found — nothing is saved yet at this point:
   - **Profile summary** — a checkbox to use it (labeled "Use this as your profile summary" if you don't have one yet, or "Replace your existing profile summary with this" if you do), with the extracted text shown in an editable box once checked.
   - **Skills** — any skills found that aren't already in your library, editable before saving, with an **Add skill** option.
   - **Experience**, **Education**, **Certifications** — each extracted entry has a checkbox (checked by default) to include or exclude it, and its bullet points/details are editable inline before saving.
4. Click **Add to library** (shows "Saving…") to save everything still checked. Click **Cancel** to discard the whole import instead.

## Notes

- Sidebar and multi-column CV layouts are handled fine. The one thing that can't be read is a scanned/image-only PDF with no actual selectable text in it.
- If nothing new is found (e.g. all the skills already exist and nothing else extracted), you'll see: "Nothing new was found to import — everything may already be in your library."
- Anything you leave unchecked is simply not imported — it won't be saved anywhere.
- Everything imported lands in the same CV components library (profile summary, skills, experience, education, certifications) used for manual entry — an imported entry can be edited or deleted afterward the same way a manually-added one can.
